# 仓库管理系统迁移包

这个迁移包包含了将仓库管理系统从当前环境迁移到新Replit环境所需的所有工具和测试文件。

## 目录结构

- `test-server.js` - 服务器测试脚本
- `test-frontend.jsx` - 前端React测试组件
- `test.html` - 基础HTML测试页面
- `check-environment.js` - 环境检查脚本
- `setup.sh` - 环境设置脚本
- `migration-checklist.md` - 迁移清单
- `README.md` - 当前说明文件

## 使用步骤

### 1. 准备工作

首先，在Replit创建一个新的项目。推荐使用Node.js模板或空白模板，这样我们可以自定义所有配置。

### 2. 文件迁移

请参考 `migration-checklist.md` 中的文件清单，确保将所有必要的文件和目录从原项目复制到新项目中。核心目录包括：

- `client/` - 前端React应用
- `server/` - 后端Express服务
- `shared/` - 共享类型定义
- `public/` - 静态资源
- 以及所有配置文件

### 3. 环境设置

在新项目中打开终端，运行：

```bash
bash setup.sh
```

这个脚本会:
- 检查必要的目录结构
- 创建.env文件（如果不存在）
- 设置数据库连接

### 4. 检查环境

运行环境检查脚本确认所有必要组件都正确设置：

```bash
node check-environment.js
```

这个脚本会检查目录结构、配置文件、环境变量和依赖项，并提供详细报告。

### 5. 测试基础功能

#### 测试服务器

运行测试服务器以验证基本的后端功能：

```bash
node test-server.js
```

然后访问：
- `/api/health` - 检查API健康状况
- `/api/test` - 测试数据库连接
- `/test` - 显示测试HTML页面

#### 测试前端

在新项目中构建一个简单的页面，使用 `test-frontend.jsx` 中的组件来测试React和相关库是否正常工作。

### 6. 启动完整应用

确认所有测试通过后，运行完整应用：

```bash
npm run dev
```

## 故障排除

如果遇到问题，请检查：

1. 项目结构是否完整
2. 环境变量是否正确设置，特别是数据库连接信息
3. 依赖是否完全安装，可能需要运行 `npm install`
4. 前端构建是否成功，检查Vite日志

## 注意事项

- 数据库连接：确保在新环境中正确配置数据库连接字符串
- 路径问题：注意新环境中的路径可能需要调整
- 依赖版本：确保所有依赖项的版本与原项目兼容

如需更多帮助，请参考项目文档或联系管理员。
